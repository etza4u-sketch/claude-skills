What this app does

Scrapes Israeli job boards for AI engineer positions, classifies each job into a Bronze / Silver / Gold tier based on opportunity quality, detects funding signals that predict future hiring, and exposes everything through a Flask REST API consumed by a single-page web dashboard.

  • 🥉 Bronze — public listings on drushim/Indeed (high competition)
  • 🥈 Silver — fast-growing or recently-funded companies
  • 🥇 Gold — founding roles, funding signals, hidden opportunities

Urgency score formula SeniorityClassifier

ComponentValueCondition
base2.0senior/lead/architect keyword matched
base1.0no seniority match
base0.5junior/intern keyword matched
bonus+0.5per match: llm, genai, generative ai, large language model
bonus+0.4per match: rag, retrieval augmented, computer vision
bonus+0.3per match: nlp, mlops, deep learning, transformer, fine-tun
bonus+0.2per match: agent, prompt engineering, vector db, embedding
bonusmax 2.0total bonus cap
recency+0.5published today (−0.1 per day, floor 0)
tier bonus+0.5Gold tier (applied by BSGClassifier)
tier bonus+0.3Silver tier
totalmin(sum, 5.0)hard cap

Immediate alert threshold: ALERT_URGENCY_THRESHOLD = 3.5 (configurable in config.py)

BSG classifier decision tree BSGClassifier

classify(job):
  text = title + company + description (lowercased)

  ── GOLD if ANY of:
     • ≥2 GOLD_SIGNAL_PATTERNS match  ("series [abcde]", "founding engineer", "recently raised"…)
     • "founding" / "first * hire" / "build from scratch" in text
     • company in FUNDED_COMPANIES AND job.is_senior == True

  ── SILVER if ANY of:
     • company in GROWTH_COMPANIES  (known high-growth companies list)
     • ≥2 SILVER_SIGNAL_PATTERNS match  ("hybrid", "fast-growing", "scale-up"…)
     • job.is_senior AND company in FUNDED_COMPANIES

  ── BRONZE  (default fallback)

Flask server state model

_state = {
    "scanning":  bool,        # True while background thread is running
    "last_scan": str|None,    # ISO-8601 timestamp of last completed scan
    "jobs":      list[dict],  # serialised Job.to_dict() objects

Add a new job board scraper

Create a class in searchers/ that extends BaseSearcher and implements search().

# searchers/alljobs.py
import requests
from bs4 import BeautifulSoup
from datetime import datetime
from .base import BaseSearcher, Job

class AllJobsSearcher(BaseSearcher):
    source_name = "alljobs.co.il"
    SEARCH_URL  = "https://www.alljobs.co.il/SearchResults.aspx"

    def search(self, keywords: list[str], location: str = "Israel") -> list[Job]:
        jobs = []
        for kw in keywords[:3]:
            try:
                resp = requests.get(
                    self.SEARCH_URL,
                    params={"position": kw},
                    headers=self.headers,
                    timeout=10,
                )
                soup = BeautifulSoup(resp.text, "lxml")
                for card in soup.select("div.job-item")[:15]:
                    job = self._parse_card(card)
                    if job:
                        jobs.append(job)
            except Exception:
                pass
        return jobs

    def _parse_card(self, card) -> Job | None:
        # adapt selectors to actual page structure
        title_el   = card.select_one("h2 a")
        company_el = card.select_one(".company")
        if not title_el:
            return None
        return Job(
            title       = self._clean_text(title_el.get_text()),
            company     = self._clean_text(company_el.get_text()) if company_el else "Unknown",
            location    = "Israel",
            description = "",
            url         = title_el.get("href", ""),
            source      = self.source_name,
            published_at= datetime.now(),
        )

Persist to a real database

Currently the app stores everything in a JSON file. To swap in SQLite (or Postgres): 

# Example: SQLite persistence layer
import sqlite3, json
from searchers.base import Job

class JobRepository:
    def __init__(self, path="jobs.db"):
        self.conn = sqlite3.connect(path, check_same_thread=False)
        self._create()

    def _create(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS jobs (
              id TEXT PRIMARY KEY,
              tier TEXT, urgency_score REAL, is_senior INTEGER,
              title TEXT, company TEXT, location TEXT,
              url TEXT, source TEXT, published_at TEXT,
              salary TEXT, description TEXT, raw_json TEXT
            )""")
        self.conn.commit()

    def upsert(self, job: Job):
        d = job.to_dict()
        self.conn.execute("""
            INSERT OR REPLACE INTO jobs VALUES
            (?,?,?,?,?,?,?,?,?,?,?,?,?)""",
            (d["id"], d["tier"], d["urgency_score"], int(d["is_senior"]),
             d["title"], d["company"], d["location"],
             d["url"], d["source"], d["published_at"],
             d["salary"], d["description"], json.dumps(d)))
        self.conn.commit()

    def all(self) -> list[dict]:
        rows = self.conn.execute("SELECT raw_json FROM jobs").fetchall()
        return [json.loads(r[0]) for r in rows]
